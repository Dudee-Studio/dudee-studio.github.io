# Hochformatfilme – nur im Repository

GitHub Pages veröffentlicht ausschließlich den Branch `main`. Dieser Medienbranch
enthält die vollständigen 1080 × 1920 Filme. Die Querformatfilme stehen auf
<https://dudee-studio.com/projekte.html#einkaufsliste>.

Alle Fotos füllen das Bild ohne weiße Ränder. Echte Appansichten bleiben vollständig
und unverzerrt. Der englische Hauptfilm enthält englische Stimmen, Grafiktexte und
echte englische Appansichten. Die vier Detailfilme sind deutsch.

Pro Film: `abgehakt-hochformat.mp4` mit eingebrannten Untertiteln,
`abgehakt-hochformat-clean.mp4` ohne Einblendung, `captions.vtt` und `poster.jpg`.

- [Shopping, sorted. (EN)](main-video-en/abgehakt-hochformat.mp4)
- [Kostenlose Funktionen (DE)](kostenlos/abgehakt-hochformat.mp4)
- [Die Pro-Version (DE)](pro-version/abgehakt-hochformat.mp4)
- [Ausgaben verstehen (DE)](analyse/abgehakt-hochformat.mp4)
- [Community-Katalog – Vorschau 1.1 (DE)](artikelkatalog-1-1/abgehakt-hochformat.mp4)

Prüfsummen und Quellen: [manifest.json](manifest.json). Die Filme sind vollständig
decodiert; Foto-Ränder wurden an tatsächlich codierten Frames mit der randlosen
Komposition verglichen. Bei den vier neuen Detailfassungen bleiben Ton,
Bildzeiten, Untertitel und App-Kompositionen unverändert. Eine subjektive Beurteilung
der Sprecherbetonung durch Zuhören ist durch diese technischen Checks nicht belegt.

Der Community-Katalogfilm ist eine Vorschau auf Version 1.1; die Live-Freigabe des
Backends steht noch aus.
